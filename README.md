# VR Horror Experience

A virtual reality horror experience developed in Unity as a campus project at Universitas Multimedia Nusantara (UMN).

## 🎮 Overview

An immersive VR horror game built with Unity XR Interaction Toolkit, featuring a suspenseful environment where players explore and interact with objects using VR controllers.

## ✨ Features

**VR Locomotion System**
- Snap Turn and Continuous Turn mechanics for smooth player rotation
- Teleportation system to improve navigation and reduce motion sickness
- XR Origin and controller-based locomotion via Unity XR Interaction Toolkit

**VR Interaction System**
- Grabbable Object interactions for natural object manipulation
- Socket Interactors for object placement mechanics
- Haptic Feedback on hover and select events to enhance immersion

## 🛠️ Built With

- **Engine** — Unity
- **Language** — C#
- **XR Framework** — Unity XR Interaction Toolkit / OpenXR
- **Systems** — VR Locomotion, Grabbable Objects, Socket Interactors, Haptic Feedback
